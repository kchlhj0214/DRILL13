# DRILL13 게임 모드

이 폴더에서 `python main.py`를 실행합니다. Python 환경에는 pico2d와 transitions가 필요합니다.

## 조작

- 로고 표시가 끝나면 타이틀 화면으로 이동합니다.
- 타이틀에서 Space: 새 게임 시작. ESC: 종료.
- 플레이에서 좌우 방향키: 이동. Space: 선택한 공 발사.
- 잠든 상태에서 Space는 먼저 캐릭터를 깨웁니다.
- 플레이에서 I: 아이템 선택 화면 진입.
- 아이템 화면에서 0: 발사 해제, 1: 작은 공, 2: 큰 공.
- 아이템 화면에서 I: 선택을 유지하며 플레이 복귀.
- 플레이에서 P: 일시정지. 다시 P: 재개.
- 플레이에서 ESC: 타이틀 복귀. 다음 게임은 기본 작은 공과 초기 위치로 시작.

## 상태 유지

아이템 화면은 기존 플레이 위에 쌓이는 모드입니다. 선택 중에는 캐릭터와 공이 갱신되지 않으며, 복귀해도 객체를 새로 만들지 않습니다. 화면에 머문 시간은 캐릭터의 수면 대기 시간에서 제외됩니다. 모드 전환은 기존 game_framework.py를 그대로 사용합니다.

## 검증

`python -m unittest test_item_mode -v`

그래픽 로딩을 대체하고 실제 모드 및 캐릭터 로직을 검사합니다. 선택별 발사 결과, 서로 다른 공 이미지 유지, 복귀 시 객체 보존, 대기 시간 보정, 타이틀 복귀 초기화, P 토글 회귀를 확인합니다. 화면 배치는 main.py를 실행하여 확인할 수 있습니다.
