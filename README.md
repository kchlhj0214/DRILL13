# DRILL13 게임 모드

이 폴더에서 `python main.py`를 실행합니다. Python 환경에는 pico2d와 transitions가 필요합니다.

## 조작

- 로고 표시가 끝나면 타이틀 화면으로 이동합니다.
- 타이틀에서 Space: 새 게임 시작. ESC: 종료.
- 플레이에서 좌우 방향키: 이동. Space: 선택한 공 발사.
- 잠든 상태에서 Space는 먼저 캐릭터를 깨웁니다.
- 플레이에서 I: 아이템 선택 화면 진입.
- 아이템 화면에서 0: 발사 해제, 1: 작은 공, 2: 큰 공.
- 아이템 화면에서 I: 선택을 유지하며 플레이 복귀.
- 플레이에서 P: 일시정지. 다시 P: 재개.
- 플레이에서 ESC: 타이틀 복귀. 다음 게임은 기본 작은 공과 초기 위치로 시작.

## 상태 유지

아이템 화면은 기존 플레이 위에 쌓이는 모드입니다. 선택 중에는 캐릭터와 공이 갱신되지 않으며, 복귀해도 객체를 새로 만들지 않습니다. 화면에 머문 시간은 캐릭터의 수면 대기 시간에서 제외됩니다. 모드 전환은 기존 game_framework.py를 그대로 사용합니다.

## 검증

`python -m unittest test_item_mode -v`

그래픽 로딩을 대체하고 실제 모드 및 캐릭터 로직을 검사합니다. 선택별 발사 결과, 서로 다른 공 이미지 유지, 복귀 시 객체 보존, 대기 시간 보정, 타이틀 복귀 초기화, P 토글 회귀를 확인합니다. 화면 배치는 main.py를 실행하여 확인할 수 있습니다.

## 수동 확인 시나리오

자동 테스트는 그래픽을 대체하므로 다음 항목은 실제 창에서 확인합니다.

1. `python main.py`를 실행하고 로고 종료 후 타이틀 화면에서 Space를 누릅니다.
2. 좌우로 이동하고 공을 발사한 뒤 I를 누릅니다. 아이템 안내 이미지가 중앙에 표시되는지 확인합니다.
3. 2를 누르고 I로 돌아온 뒤 Space를 누릅니다. 기존 작은 공과 새 큰 공이 각 크기를 유지해야 합니다.
4. I → 0 → I → Space 순서로 입력합니다. 새 공이 생성되지 않아야 합니다. I → 1 → I로 작은 공 발사를 복구합니다.
5. 이동 키를 누른 채 I로 진입하고 방향키를 놓은 뒤 복귀합니다. 캐릭터가 계속 움직이지 않아야 합니다.
6. 아이템 화면에서 잠시 기다렸다가 복귀합니다. 선택 중 캐릭터 위치와 기존 공의 위치는 유지되어야 합니다.
7. P를 두 번 눌러 일시정지 표시와 재개를 확인합니다.
8. ESC로 타이틀에 돌아가 Space로 재시작합니다. 위치와 발사 아이템이 기본값으로 초기화되어야 합니다.
9. 아이템 화면에서 창 닫기 버튼을 눌러 프로그램이 종료되는지 확인합니다.

자동 테스트는 현재 8개이며, 반복 진입 시 모드 누적 방지, 메뉴 입력 격리, 창 종료, 이동 키 해제, 이미지 캐시 및 잘못된 공 종류 처리도 포함합니다. 위 수동 항목은 실행자가 별도로 확인하는 절차입니다.
